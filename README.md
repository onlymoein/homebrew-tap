# Homebrew tap for MacSync

```
brew tap onlymoein/tap
brew trust onlymoein/tap   # Homebrew asks you to trust a tap once
brew install --cask macsync
```

Already have MacSync in Applications from a download? Run `brew install --cask --force macsync` once.
Installs and upgrades work whether MacSync is open or not; it restarts itself into the new version.

MacSync keeps your Macs set up the same way: Dock, apps and settings through iCloud Drive.
Source and releases: https://github.com/onlymoein/macsync
